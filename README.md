# CHEKI ARCHIVE

実物のチェキを撮影し、フチや手書きのメッセージを含めて JPEG に保存する日本語の Web アプリです。HTML、CSS、JavaScript だけで動作します。画像はブラウザ内で処理し、元の写真はそのまま残ります。アカウント、API キー、有料サービスは不要です。

## Galaxy での使い方

1. Android の Chrome で公開ページを開きます。
2. **カメラで撮影**を押し、チェキの四隅が写真の中に入るように背面カメラで撮ります。撮影済みなら **ギャラリーから選択** を使います。画像を開けない場合は、カメラを高効率画像（HEIF）から JPEG に切り替えて撮り直してください。
3. 自動検出が終わったら、紫色の丸がチェキの**外側の角**に合っているか確認します。丸は指で微調整できます。検出できなかった場合は、画像全体の四隅から手動で合わせられます。四隅が大きくずれた場合は **手動でやり直す** を押してください。mini の横置きや WIDE などの場合は **フィルム** も合わせます。
4. **補正してプレビュー**を押します。フチやサインが欠けていたら、丸を調整してもう一度補正します。
5. **JPEGをダウンロード**を押します。保存した画像は Chrome のメニューにある **ダウンロード**、または Galaxy の **マイファイル → ダウンロード** から開けます。

キーボードでは、Tab で丸を選び、矢印キーで動かせます。Shift を押しながらだと大きく動きます。

自動検出は画像の縮小コピーを端末内で解析します。明暗差に加え、布目などの質感の変化と、四辺が作る形を手がかりにします。フチを残しやすいように、検出した外周より少し外側に丸を置きます。黒いフチが背景に溶け込むときや、反射で外周が見えないときは、手動で調整するか、背景や光の向きを変えて撮り直してください。

JPEG は元の解像度の画像を使い、ブラウザのエンコーダーに品質 `0.95` を指定して作成します。出力の解像度は指定範囲とフィルムの縦横比から決まり、大きい写真ではメモリ使用量を抑えるため最大約 1,200 万画素に縮小します。

## ローカルで試す

Python 3 がある場合、リポジトリのフォルダーで以下を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

同じ PC の Chrome で `http://127.0.0.1:8000` を開きます。JavaScript モジュールを使うため、HTML ファイルを直接開く代わりに HTTP サーバーを使います。

Node.js 22.7 以降では `node --test tests/detect.test.mjs` で、合成画像を使った自動検出テストを実行できます。

## GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を **Deploy from a branch** にします。
3. アプリのファイルが入った公開用ブランチと **/ (root)** を選び、**Save** を押します。
4. デプロイ後に同じ画面に表示される HTTPS URL を、Galaxy の Chrome で開きます。

ビルドや依存パッケージのインストールは不要です。
